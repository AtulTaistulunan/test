### 二、單元一：【諮商輔導】高頻考點精華

#### （一）學生輔導法規：三級輔導／三級預防體制
- **發展性輔導（初級預防）**：
  - **對象與目標**：全校／全體學生；促進心理健康、預防適應問題。
  - **常見作法**：班級輔導活動、生命教育、情緒教育、生涯探索、性平宣導。
  - **題幹關鍵字**：全校、全班、發展、預防、增能。
- **介入性輔導（次級預防）**：
  - **對象與目標**：適應困難、出現重複性偏差行為、瀕臨中輟者。
  - **常見作法**：專輔個別諮商、小團體輔導、認輔制度、親師諮詢、個案管理。
  - **題幹關鍵字**：持續困擾、早期介入、個別輔導、生活適應欠佳。
- **處遇性輔導（三級預防）**：
  - **對象與目標**：嚴重偏差、自傷自殺危機、精神疾患、重大創傷或受暴個案。
  - **常見作法**：跨專業網絡合作、心理治療、社工進駐、醫療精神急診轉介。
  - **題幹關鍵字**：自傷自殘、意圖傷害他人、受暴虐待、重大創傷、危機介入。
- **【速記口訣】**：*全體預防是發展；出現困難早介入；嚴重危機做處遇！*

#### （二）輔導專業倫理與危機處遇
1. **保密原則 vs. 保密例外（生命安全最高原則）**：
   - 原則上嚴格保密；但遇**自傷、傷人、兒少保護（虐待/家暴）、性侵害/性騷擾、法定通報或法官傳喚**時，構成保密例外。
   - **處置 SOP**：真誠傾聽關懷 → 評估致命性與急迫性 → **寸步不離、不讓學生獨處** → 啟動校內機制通報家長與校安 → 法定 24 小時通報 → 醫療/心理轉介 → 長期追蹤。
2. **知情同意（Informed Consent）**：
   - 晤談開始前必須以學生能懂的語言，說明目標、歷程、權利及「保密界限與例外」。
3. **雙重／多重關係（Multiple Relationships）**：
   - 避免同時擔任「評分授課教師」與「個別諮商心理師」；利益衝突時當事人福祉優先，尋求同儕督導或優先轉介。

#### （三）主要諮商學派大對照表

| 學派名稱 | 核心人性觀與病理觀 | 代表性技術與題幹關鍵字 | 易混淆考點剖析 |
| :--- | :--- | :--- | :--- |
| **精神分析** | 潛意識衝突、童年早期經驗、性心理發展 | 自由聯想、夢的解析、移情與反移情、防衛機轉 | 重「過去與潛意識挖掘」，絕不直接給建議。 |
| **阿德勒個體心理學** | 追求優越、自卑補償、目的論、社會情懷 | 早期回憶、家庭星座、私人邏輯、潑冷水、假裝技術 | 強調「行為目的（追求歸屬）」，非佛氏決定論。 |
| **個人中心學派** | 人有自我實現傾向、有機體評價歷程 | 真誠一致、無條件積極關注、同理心反映 | 諮商師非指導者，不詮釋、不說教、不急著給解方。 |
| **完形治療學派** | 身心整體、接觸障礙（內射/投射/迴向/偏折/融合） | 此時此刻（Here & Now）、空椅法、雙椅技術、誇張技術 | 重「當下的身體覺察與未竟事宜處理」。 |
| **理情行為治療 (REBT)** | 非理性信念（絕對化要求、糟糕透頂、低挫折容忍） | ABCDE 架構、實徵/邏輯/務實駁斥（D）、羞恥攻擊練習 | Ellis 主張直接哲學辯證，抓「必須、應該、完了」。 |
| **貝克認知治療 (CBT)** | 自動化負向思考、認知三夾板（我/世界/未來） | 思考紀錄表、向下箭頭技術、合作檢驗證據、行為實驗 | 像「合作科學實驗」，找客觀事實推翻認知扭曲。 |
| **現實治療與選擇理論** | 全人行為四輪車（做/想/感覺/生理）、五大需求滿足 | WDEP 系統、SAMIC3 行動計畫、優質世界（Quality World） | 不探究過去藉口，聚焦「你現在做的事有幫助嗎？」。 |
| **焦點解決短期諮商 (SFBT)** | 不探究病理成因、沒壞別修、有用多做、沒效換招 | 奇蹟問句、例外問句、量尺問句、因應問句、讚賞 | 不問「為什麼生病」，找「問題何時沒發生過（例外）」。 |
| **敘事治療** | 人不是問題，問題才是問題；解構文化主流論述 | 問題外化對話、獨特結果（閃亮時刻）、重寫故事、外部見證 | 替問題命名擬人化（怪獸/烏雲），分離人與問題。 |
| **家族系統治療** | 個人症狀是家庭系統失衡的表現（IP 當事人） | 薩提爾冰山與五姿態、米紐慶結構界線、鮑溫自我分化 | 從家庭代際與互動脈絡看問題，推動去三角化。 |

- **諮商技術秒殺指南**：
  - *「你聽起來感到很委屈，也很渴望被看見」* ➔ **情感反映（Reflection of Feeling）**
  - *「你嘴上說不在乎，但你的拳頭握得很緊、臉色發白」* ➔ **面質（Confrontation）**
  - *「如果今晚發生奇蹟，明天會有何不同？」* ➔ **奇蹟問句（Miracle Question）**
  - *「如果 10 分代表完全有信心，你現在是幾分？如何前進一分？」* ➔ **量尺問句（Scaling Question）**

### 三、單元二：【班級經營】高頻考點精華

#### （一）核心原則：預防勝於處罰、教導勝於壓制、修復勝於羞辱
- **班規建立黃金法則**：
  1. 開學第一天或第一週，與學生**共同討論訂定少量（3~5條）、具體正面（少用「不准」、多用「要」）**的班規。
  2. 明確說明行為期待、原因及違反後的補救程序。
  3. 優先肯定具體正向行為，強化良好常規。

#### （二）主要班級經營理論對照

| 學者／理論模式 | 核心概念與技術 | 題幹關鍵字與秒殺線索 |
| :--- | :--- | :--- |
| **庫寧（Kounin）班級生態學** | 全面關照（Withitness）、同時處理（Overlapping）、動能與順暢（Momentum & Smoothness）、避免飽和（Satiation Avoidance）、團體警報、漣漪效應 | 老師背後長眼睛、眼觀四面、活動轉換不延宕、不過度詳述（Overdwelling）、不碎裂化。 |
| **德瑞克斯（Dreikurs）邏輯後果** | 學生偏差行為四大錯誤目標：**獲得注意 ➔ 爭取權力 ➔ 尋求報復 ➔ 展現無能**；民主式領導。 | 教師的情緒是線索：心煩＝要注意；被威脅被激怒＝爭權力；受傷＝報復；絕望無力＝展現無能。 |
| **康寧（Canter）果斷紀律** | 教師有權教導、學生有權學習；溫和而堅定的果斷態度、階梯式紀律後果。 | **「破唱片技術（反覆冷靜堅持指令）」**、明確正向期待、私密登記夾、正向肯定。 |
| **瓊斯（Jones）積極班級紀律** | 肢體語言設限、座位佈局減少師生距離、時間浪費最小化。 | **VIPs 視覺教學計畫、身體語言 Camping Out、PAT 增強活動時間**、Praise-Prompt-Leave（10秒）。 |
| **葛拉瑟（Glasser）現實與無輸教室** | 滿足五大心理需求、消除「老闆型管理（Boss）」、推行「領導型管理（Lead）」。 | 教室圓圈班會（無輸會議）、不接受藉口、不使用外部威脅利誘、引導自我評估。 |
| **高登（Gordon）教師效能訓練 (T.E.T.)** | 接納線（Acceptance Line）、問題歸屬（誰擁有問題）、雙贏無輸法。 | **「我訊息（I-Message：行為＋後果＋感受）」**、積極傾聽（Active Listening）、避免溝通十二絆腳石。 |

#### （三）教檢最常考：處罰 vs. 邏輯後果 vs. 自然後果

| 類別 | 定義與本質 | 情境範例 | 效果評估 |
| :--- | :--- | :--- | :--- |
| **自然後果（Natural）** | 不經人為干預，自然法則產生的自然結果。 | 忘記帶雨傘，下雨自己淋濕；不吃早餐，第二節肚子餓。 | 最具說服力，**但危及生命安全（如衝馬路）絕對禁用**！ |
| **邏輯後果（Logical）** | 教師設計，且與不當行為**具有邏輯相關性、尊重且合比例**。 | 打翻牛奶，負責拿抹布擦乾淨；弄亂圖書角，下課負責整理復原。 | 教導承擔責任與修復損害，培養自律。 |
| **處罰（Punishment）** | 人為強加的不舒服或羞辱，**與行為毫無內在關聯**。 | 上課講話，罰抄課文 50 遍；沒交作業，罰跑操場 10 圈。 | 產生怨恨、恐懼或陽奉陰違，無法學會正確行為。 |

- **【速記口訣】**：*自然後果自己來；邏輯後果有關聯；處罰只痛未必學！*

### 四、單元三：【適性輔導】高頻考點精華

#### （一）融合教育核心概念辨析

| 專有名詞 | 核心法律與教育意義 | 考題判斷重點 |
| :--- | :--- | :--- |
| **融合教育（Inclusive Ed）** | 特殊需求學生與同儕在普通班一起學習，提供足夠支持並實質參與。 | 融合不是「擺在普通班不管」，必須有實質支持與參與。 |
| **最少限制環境（LRE）** | 依個別需要，在最大可能範圍內與普通學生同班，限制最少。 | 不是「普通班至上」，若普通班完全無法滿足需要，特教班也是 LRE。 |
| **合理調整（Accommodation）** | **「不改學習目標，只改參與、學習或評量方式」**。 | 延長時間、字體放大、報讀、輔具、無障礙動線、以口試代筆試。 |
| **課程修改（Modification）** | **「降低標準或改變學習目標」**。 | 國三生改學國小三年級基礎運算、簡化課程難度與評量指標。 |
| **通用設計學習（UDL）** | **「事前為全體學生設計」**，從一開始就提供多元學習入口。 | 預防性設計、減少後續個別調整負擔（非針對單一特教生）。 |
| **個別化教育計畫（IEP）** | 依特教學生的個別獨特需求，由專業團隊量身訂定的計畫。 | 專屬單一特教學生、具法定時程與強制性規範。 |

- **【秒殺口訣】**：
  - *調整改路徑（目標不變）；修改改目標（標準降低）！*
  - *UDL 先為大家設計；IEP 再為個人規劃！*

#### （二）個別化教育計畫（IEP）法定關鍵規範
- **法定時程**：
  - **新安置／轉入學生**：入學或確定安置後 **1 個月內** 完成訂定。
  - **舊生**：於**開學前**訂定完成。
  - **檢討頻率**：**每學期至少檢討 1 次**（重大變故可隨時召開臨時會議修訂）。
- **團隊法定成員**：
  - 學校行政人員、特教教師、普通班導師、家長／監護人、相關專業人員（OT/PT/ST/心理師/社工師），**並得邀請學生本人列席（尤其是轉銜階段）**。
- **必備核心內容**：學生現況能力 ➔ 年度／學期教育目標 ➔ 特教與相關支持服務 ➔ 評量與教學調整 ➔ 轉銜輔導服務。

#### （三）通用設計學習（UDL）三大核心原則
1. **多元表徵方式（Representation）**：提供不同的輸入管道，讓學生「**看懂、聽懂**」（文字＋圖像＋語音＋實物）。
2. **多元行動與表達方式（Action & Expression）**：提供不同的輸出管道，讓學生「**展現所學**」（書寫、打字、口頭發表、繪圖、戲劇）。
3. **多元參與涉入方式（Engagement）**：激發學習動機，讓學生「**想學、願意堅持**」（自主選擇主題、同儕合作、挑戰性分級）。
- **【口訣】**：*看懂＝表徵；做出＝表達；想學＝參與！*

#### （四）行為功能評量（FBA）與正向行為支持（PBS）
- **ABC 行為模式分析**：
  - **A（Antecedent 前事）**：行為發生前的情境、刺激與觸發點。
  - **B（Behavior 行為）**：可觀察、可測量的不當行為本體。
  - **C（Consequence 後果）**：行為發生後環境給予的反饋（個案獲得或逃避了什麼）。
- **問題行為四大核心功能**：
  1. **獲得注意**（獲得師生關注）
  2. **獲得實質物品／偏好活動**
  3. **逃避／拒絕嫌惡任務**（逃避困難題目、逃避吵鬧環境）
  4. **感官刺激／自我調節**（前庭刺激、本體感覺刺激）
- **正向行為支持計畫（PBS / BIP）四大成分**：
  - 前事環境調整 ➔ 教授功能相當之替代行為 ➔ 區別性增強正向行為 ➔ 危機應變與消弱。
- **【口訣】**：*先找功能，再教替代；調整前事，增強好事！*

#### （五）特殊需求學生特質與教學調整首選對照表

| 特教類別 | 典型核心特質與題幹線索 | 教學與班級經營首選調整策略 |
| :--- | :--- | :--- |
| **注意力不足過動症 (ADHD)** | 衝動離座、容易分心、多步驟指令遺漏、組織力弱 | 座位靠近教師遠離門窗、任務切成微步驟、檢核表、立即具體回饋、運動調節。 |
| **自閉症譜系障礙 (ASD)** | 堅持固著性、轉換焦慮、社交語用困難（字面直譯）、感官敏感 | **結構化教學（TEACCH 視覺作息表）**、預告變動、**社交故事（Social Stories）**、感官減敏。 |
| **學習障礙 (LD)** | 智力正常但讀寫算有顯著落差（非感官或文化不利所致） | **多感官教學（Orton-Gillingham VAKT）**、報讀服務、延長作答時間、概念圖鷹架。 |
| **情緒行為障礙 (EBD)** | 情緒劇烈失控、攻擊抗拒、長期退縮適應困難 | FBA 功能分析、建立安全冷靜角、**Colvin 去激化七階段**、教導情緒調節策略。 |
| **資賦優異** | 學習速度極快、高思考靈活性、求知慾旺盛 | **充實制（加深加廣、專題探究）**、**加速制（提早修課、免修、跳級）**、課程濃縮。 |

- **ASD 三大對策秒殺判斷**：
  - *流程混亂、不知下一步、害怕變動* ➔ **結構化教學（TEACCH）**
  - *不懂輪流、不理解社交潛規則* ➔ **社交故事（Social Stories）**
  - *無口語或口語表達嚴重受限* ➔ **圖片兌換溝通系統（PECS）**
  - **【口訣】**：*流程亂用 TEACCH；社交不懂用故事；想說不出用 PECS！*

#### （六）生涯發展理論：Super vs. Holland
1. **舒伯（Super）生涯發展理論**：
   - 核心：一生長期的自我概念實踐，包含「生活廣度（五大階段）」與「生活空間（多重角色彩虹）」。
   - **五大階段**：**成長期 ➔ 探索期（14~24歲青少年核心） ➔ 建立期 ➔ 維持期 ➔ 衰退期**。
   - **【速記口訣】**：*成、探、建、維、衰，Super 彩虹看一生！*
2. **荷倫（Holland）職業興趣理論 (RIASEC 六角型)**：
   - 核心：人格特質與工作環境的相互契合適配度。
   - **RIASEC 六大類型**：
     - **R（實用型）**：操作機械、手動實作、戶外活動。
     - **I（研究型）**：抽象思考、科學分析、數理解謎。
     - **A（藝術型）**：創作表達、直覺審美、不受拘束。
     - **S（社會型）**：助人教導、人際溝通、關懷照顧。
     - **E（企業型）**：說服引導、領導管理、追求成就。
     - **C（事務型）**：條理規矩、資料數據、精確細緻。
   - **【速記口訣】**：*實、研、藝、社、企、事，六角相鄰契合高！*

### 五、三大單元「一句話秒殺」易混淆對照表

1. **初級 vs 次級 vs 三級輔導**：全體宣導預防（初級）／出現困難及早介入（次級）／嚴重危機跨專業醫療（三級）。
2. **個人中心 vs 現實治療**：接納同理相信成長（個人中心）／選擇責任現在行動（現實治療）。
3. **理情治療 (REBT) vs 認知治療 (CBT)**：抓「必須絕對」直接駁斥（REBT）／當作假說合作找證據（CBT）。
4. **焦點解決 (SFBT) vs 敘事治療**：向前看找例外與奇蹟（SFBT）／人非問題，外化解構重寫故事（敘事）。
5. **自然後果 vs 邏輯後果**：自然發生不人為（自然）／教師設計具邏輯補救性（邏輯）。
6. **合理調整 vs 課程修改**：不改目標只改路徑方式（調整）／直接降低目標難度與標準（修改）。
7. **通用設計 (UDL) vs 個別化計畫 (IEP)**：事前為全體多元設計（UDL）／事後為個別特教生量身定做（IEP）。
8. **行為功能 (FBA) vs 正向支持 (PBS)**：以 ABC 找行為功能（FBA）／以非懲罰手段教導替代行為（PBS）。
9. **資優充實制 vs 加速制**：加深加廣不跳級（充實）／加快進度跳級提早修（加速）。
10. **Super vs Holland**：看一生角色發展歷程（Super）／看人格特質與職業環境適配（Holland）。
